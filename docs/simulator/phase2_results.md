## 핵심 인사이트

1. **auto가 12개월 bear 구간에서 압도적** — v3-bear가 6종목만 BUY, 평균 +121.7% (선별도의 힘)
2. **bull에서는 v1(엄격)이 oracle** — but auto(v6)도 +3.5%p로 충분히 근접
3. **neutral 데이터 없음** — 4개 시점 모두 bull 또는 bear, neutral 검증 미완
4. **v3-defensive는 최악** — bear에서 BUY 0개 (전부 WATCH로 격하) → 스프레드 계산 불가
5. **auto의 bull→v6 매핑을 v1으로 변경하면** oracle에 더 근접 가능 (개선 후보)

## 개선 제안

- bull 레짐 auto 매핑: v6 → **v1** 변경 고려 (스프레드 +4.5 vs +3.5)
